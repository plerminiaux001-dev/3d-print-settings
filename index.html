3D Printing Reference: CAD & G-code

1. Common G-code Commands

Essential commands for manual terminal entry or custom layer scripts in Snapmaker Orca.

Command Name Example Function
G28 Home All G28 Returns all axes to the (0,0,0) position.
G1 Linear Move G1 X50 Y50 E10 F1200 Moves to coordinates while extruding 10mm of filament.
G92 Set Position G92 E0 Resets the extruder distance (essential before layer swaps).
M104 Set Hotend Temp M104 S230 Sets temp and moves to next line immediately.
M109 Wait for Hotend M109 S230 Sets temp and waits until reached before continuing.
M140/M190 Bed Temp M190 S60 Set (M140) or Wait for (M190) bed temperature.
M106 Fan Speed M106 S255 Controls cooling fan (0-255).
M600 Filament Change M600 Pauses print for manual filament swap.

2. Solutions in Fusion 360

Method A: Offset Face (The Correct Way)

  1. Go to Solid Tab > Modify > Offset Face.
  2. Select the angled faces (flanks) of the thread.
  3. Enter value (e.g., -0.15mm).
Printer Type Offset Value Notes
FDM (Standard) -0.15 mm Snapmaker U1 / Kobra 3 well-tuned.
FDM (Loose) -0.20 mm For high-speed prints or older machines.
SLA (Resin) -0.05 mm High accuracy.
